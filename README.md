# 🏢 Emaar Tools Platform

A comprehensive suite of **15 web applications** built for internal productivity, communication, and media management. 

## 🚀 Live Website
The platform is fully deployed and running on Firebase:
👉 **[https://emaar-tools.web.app](https://emaar-tools.web.app)** 

## 🛠️ The 15 Apps
### Productivity & Documents
- 📝 **Emaar Text**: Rich text editor
- 📊 **Emaar Sheet**: Spreadsheet with Excel formulas
- 🎬 **Emaar Show**: PowerPoint-style presentations
- 📋 **Emaar Forms**: Form and survey builder
- 🗒️ **Emaar Notes**: Sticky notes board
- 📄 **Emaar PDF**: Image to PDF converter

### Media & Communication
- 💬 **Emaar Chat**: Real-time group chat with custom rooms
- 📧 **Emaar Mail**: Internal email system
- 🎥 **Emaar Tube**: Curated YouTube video library

### Utilities
- 🧮 **Emaar Calc**: Scientific calculator & currency converter
- 📅 **Emaar Calendar**: Event scheduling
- ⏱️ **Emaar Clock**: Clock, stopwatch, and timer
- 📱 **Emaar QR**: QR code generator
- 🔐 **Emaar Pass**: Secure password generator
- 🧠 **Emaar AI**: Local rule-based AI assistant

## 🔒 Authentication
The platform uses **Firebase Authentication** (Email/Password and Google Login) to secure access.

## 💻 Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend / Database**: Firebase (Firestore, Auth, Hosting)
- **Libraries**: SheetJS, jsPDF, QRCode.js, Phosphor Icons
