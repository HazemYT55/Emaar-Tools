## Reporting a Vulnerability

At Emaar Tools, we take the security of our internal platform seriously. 

If you discover a security vulnerability in this project, please **do not** open a public issue. Instead, please report it privately to the project maintainers:

- **Email:** security@emaar-tools.web.app *(placeholder)*
- **GitHub:** You can use the **"Security"** tab in this repository to privately report a vulnerability.

### What to include in your report:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on the system.

We will acknowledge your report within 48 hours and provide an estimated timeline for a fix.
